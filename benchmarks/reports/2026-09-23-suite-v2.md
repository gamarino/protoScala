# protoScala benchmarks — 2026-09-23 (interleaved re-run)

> **Supersedes** `2026-09-23-suite.md` (kept for history). That run used 5
> timed samples per cell and reported a bare median with no spread. This run
> uses 7 timed samples per cell (2 discarded warmup), reports `[min-max]`
> spread beside every median, and records the load average at start,
> midpoint and end. The machine is the maintainer's daily-driver desktop —
> VS Code, Chrome and PyCharm run throughout, the load-average floor is
> roughly 2-3 on 12 logical CPUs, and there is no quiet window to wait for.
> Ratios to CPython are the primary result; absolute milliseconds are
> indicative only. Comparing this run's medians against the superseded
> run's single-sample medians, every workload's protoScala figure moved
> less than 10%, and no cell moved more than protoScala Release's
> `str_concat`/`range_iterate` rows (see the README performance section for
> the full comparison) — both inside the spread shown below, i.e. noise,
> not a regression or an improvement.

- **Date:** 2026-09-23 05:37
- **Machine:** AMD Ryzen 5 5500U with Radeon Graphics — 6 cores, 12 logical CPUs; Linux 7.0.0-31-generic (x86_64)
- **protoScala:** commit `3703759-dirty`; `build_release/protoscala` is RelWithDebInfo; `build_bench/protoscala` is Release
- **Load average (1/5/15 min):** 3.37 / 6.73 / 6.83 at start, 4.08 / 6.19 / 6.63 at midpoint, 4.39 / 5.87 / 6.49 at end (the run waited 120 s for the 1-minute load to drop below 4.0)
- **Method:** 2 warmup + 7 timed runs per cell, interleaved across runtimes (round-robin: one sample of each runtime, then the next, so ambient load hits every column alike); median wall-clock of a cold process (start-up included), spread reported as `[min-max]` beside every median. This machine is a daily-driver desktop (VS Code, Chrome and PyCharm run throughout); ratios to CPython are the primary result, absolute milliseconds are indicative only. Every run's printed result is verified; a wrong result, non-zero exit or timeout marks the cell FAILED and it is excluded from every aggregate.
